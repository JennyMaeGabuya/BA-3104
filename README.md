# BA-3104
Web-Based Student Complaint and Feedback Management System
For Batangas State University – The National Engineering University
JPLPC – Malvar Campus

Project Overview
The Web-Based Student Complaint and Feedback Management System is a centralized digital platform that allows students of Batangas State University – JPLPC Malvar Campus to formally submit complaints and feedback regarding university services, facilities, and personnel.
The system promotes transparency, accountability, and better communication by offering a structured, secure, and trackable method for reporting concerns. It also provides the administration with an organized dashboard to efficiently monitor, manage, and resolve reported issues.

Objectives
General Objective
To design and develop a secure, centralized web-based platform where students can submit, manage, and monitor complaints and feedback, ensuring proper documentation and efficient communication with the university administration.

Specific Objectives
* To create a secure platform for submitting complaints and feedback
* To provide a real-time tracking system using a reference number
* To develop an administrative dashboard for managing and responding to reports
* To implement a notification system for status updates
* To store data in a structured database for easy retrieval and future reference
* To generate reports for analysis and decision-making
* To ensure transparency by keeping a record of all actions and responses.

Target Users
* Students – Can submit and track complaints and feedback.
* Administrators – Can manage, monitor, and resolve reports.

Key Features
Student Side
* User Registration and Login
* Complaint and Feedback Submission
* Real-Time Tracking of Report Status
* Notification Alerts

Admin Side
* Secure Admin Login
* Complaint Review and Categorization
* Status Update (Pending, In Progress, Resolved)
* Report Management and Documentation
* Data Analysis and Summary Reports

Development Methodology
The system was developed using the Agile Development Model, which includes the following phases:
* Planning Phase – Identification of system requirements and objectives
* Design Phase – Creation of system layout, wireframes, ERD, and DFD
* Development Phase – Coding and implementation of system modules
* Testing Phase – Detection and correction of errors and bugs
* Review and Improvement Phase – System refinement and optimization

System Limitations
* The system does not handle academic processes such as:
        • Grading
        • Course Registration
        • Faculty Evaluations
* Complaints are not resolved automatically (requires admin action)
* Integration with email and social media is limited
* Urgent or sensitive concerns still require face-to-face consultation
* Irrelevant or false reports may still be submitted (subject to admin review)

Technology Stack (Suggested)
* Frontend: HTML, CSS, JavaScript
* Backend: PHP / Node.js
* Database: MySQL
* Server: XAMPP / Online Hosting
* Add-ons / Plugins: For notifications and dashboard enhancement
