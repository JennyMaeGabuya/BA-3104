# Clinic Scheduling System

This project is a web-based appointment scheduling system for the BatStateU campus clinic.  
Students and Patients can book consultations, view available schedules, and receive updates.

## Features
- Online appointment booking
- Admin dashboard
- Email notifications
- Reschedule and cancellation
- Responsive UI

## Installation
1. Clone the repository
2. Import `booking_management.sql` into phpMyAdmin
3. Configure database in `/config/db_connection.php`
4. Run the project on XAMPP's localhost
